# 실측 사진 데이터 안내

이 폴더는 네 가지 인쇄 배경에서 같은 다섯 벌의 옷을 찍은 사진 모음입니다. 배경별 다섯 장씩, 모두 20장입니다. 자동 측정 과정을 확인하고, 파일 이름에 적힌 줄자 기준값과 사진 분석값의 차이를 비교하는 데 사용합니다.

## 폴더와 배경

| 폴더 | 배경 | 인쇄 기준 |
| --- | --- | --- |
| `point/` | 동그란 점 | A0(84.1 × 118.9cm), 점 지름 1cm, 9 × 12개, 점 중심 간격 10cm |
| `cross/` | 모눈 | A0, 5cm 격자 16 × 23칸 |
| `ChArUco/` | 테두리 ChArUco 매트 | A0, DICT_4X4_1000, 칸 2.5cm, 검은 표식 1.875cm, 가운데 실측 영역 70 × 105cm |
| `ChaArUco_Cross/` | 네 칸 ChArUco 매트 (`charuco_cross`) | A0, DICT_4X4_1000, 칸 2.5cm, 각 칸 32.5 × 50cm |

ChArUco 네 칸 폴더 이름은 데이터에 들어 있는 철자 `ChaArUco_Cross`를 유지했습니다. 이름을 찾아볼 때는 `charuco_cross`도 같은 배경으로 보면 됩니다. 인쇄물은 반드시 실제 크기 100%로 출력해야 합니다. 각 PDF의 크기 확인 표식은 5cm 간격 10칸입니다.

## 파일 이름 읽기

`<배경 약자>_<옷 번호>_w<너비>_h<길이>.jpg` 형식입니다. 예를 들어 `p_1_w55_h65.jpg`는 점 배경(point)에서 찍은 1번 옷이며, 기준 너비 55cm, 기준 길이 65cm라는 뜻입니다. 사진의 EXIF 회전 정보가 있을 수 있으므로 분석할 때 사진 방향을 바로 세워야 합니다.

| 번호 | 옷 | `w` 너비 기준 | `h` 길이 기준 |
| --- | --- | --- | --- |
| 1 | 상의 외투 | 가슴 너비(겨드랑이 아래) | 옷 기장 |
| 2 | 흰 크롭티셔츠 | 가슴 너비(겨드랑이 아래) | 옷 기장 |
| 3 | 원피스 | 가슴 너비 | 원피스 기장 |
| 4 | 점퍼 | 가슴 너비(겨드랑이 아래) | 옷 기장 |
| 5 | 바지 | 허리를 평평하게 놓았을 때 너비 | 옆선 기장 |

파일명의 `w`와 `h` 숫자는 개발 중 측정 위치를 조정하고 결과를 비교하는 기준입니다. 자동 측정 실행 중에는 파일명 숫자를 읽어 대입하지 않습니다. 값은 사진 속 매트 크기와 옷 윤곽에서 따로 계산합니다. 같은 20장으로 설정을 조정하고 비교하므로, 이 결과만으로 새 옷의 정확도를 검증했다고 볼 수는 없습니다.

## 데이터 한계

- 옷마다 네 배경 사진이 한 장씩 있습니다. 옷은 다섯 종류뿐이고 각 종류의 새 사례는 하나라, 프로필이 이 데이터에 맞춰져 있을 수 있습니다. 새 옷 전체에 통하는 AI 학습이나 정확도를 보장할 수 없습니다.
- 사진에는 정답 너비와 길이만 있고 옷 테두리 마스크나 측정선 주석은 없습니다. 흰 크롭티셔츠처럼 매트와 색이 비슷한 옷은 윤곽을 놓칠 수 있습니다.
- 겉옷 소매 폭은 가슴 너비와 다르고, 바지의 전체 폭도 허리 너비와 다릅니다. 종류별 측정선을 별도로 확인해야 합니다.
- 측정 실패도 결과에 남깁니다. 오차 평균은 자동 측정이 성공한 사진만 대상으로 하고, 성공률은 전체 사진 수를 기준으로 계산합니다. 평균을 볼 때는 표본 수도 함께 확인합니다.

## 로컬 분석 실행

ChArUco 표식 검출과 원근 보정에 OpenCV의 contrib 모듈을 사용합니다. 프로젝트는 프레임워크를 추가하지 않고 Python 분석 도구에만 이 라이브러리를 사용합니다. 화면은 기존 Python 서버와 Vanilla JavaScript로 표시합니다.

```powershell
python -m pip install -r requirements-vision.txt
python -m tools.measure_dataset --output server-data/measure-dataset-report
python server.py
```

분석 결과 화면은 `http://localhost:8000/measure-dataset.html`에서 엽니다. 결과 파일은 `server-data/`에 생성되며 Git에 추가하지 않습니다.

두 번째 분석 도구 `measure_pipeline/`(기하 기반, 옷 번호별 비율 없이 겨드랑이·어깨선·밑단을 직접 찾음)은 다음처럼 실행합니다. 결과는 `measure_pipeline/output/results.md`와 `overlay/`에 남습니다.

```powershell
python -m pip install opencv-contrib-python pymupdf   # pymupdf 는 PDF 레이아웃을 다시 뽑을 때만 필요
python measure_pipeline/run_dataset.py                 # --debug 를 붙이면 중간 마스크도 저장
```

## 인쇄 배경의 정확한 치수 (PDF 벡터에서 읽음)

좌표는 A0 용지 왼쪽 위를 원점으로 x 오른쪽, y 아래, 단위 mm 입니다. 자동 보정은 이 값으로 '용지 mm → 사진 px' 대응을 만듭니다.

| 배경 | 표식 위치 | 비고 |
| --- | --- | --- |
| `point/` 점 | 점 중심 x = 20.5 + 100·i (i = 0..8), y = 44.5 + 100·j (j = 0..11), 지름 10 | 9 × 12 = 108개 |
| `cross/` 격자 | 세로선 x = 20.5 + 50·i (i = 0..16), 가로선 y = 19.5 + 50·j (j = 0..23), 선 굵기 0.6 | 교차점 17 × 24, 가장자리에 cm 눈금 숫자 |
| `ChArUco/` 테두리 | 보드 원점 (20.5, 19.5), 32 × 46칸, 칸 25, 마커 18.75, 테두리 2칸 폭에만 마커 148개 | 안쪽 흰 영역 x 70.5~770.5, y 69.5~1119.5. 측정 영역을 알리는 회색 점선 사각형 (78.5, 77.5)~(762.5, 1111.5). PDF가 양면이라 **뒷면 4칸 무늬가 비쳐 보임** |
| `ChaArUco_Cross/` 4칸 | 테두리는 위와 같고, 가운데 세로 띠 x 395.5~445.5, 가로 띠 y 569.5~619.5 에 마커 추가(총 216개) | 마커 ID 배치는 테두리 매트와 다름 (`measure_pipeline/layouts/*.json`) |

모든 PDF 아래쪽 가운데(용지 끝에서 14~40 mm)에 작은 설명 글씨가 있습니다.

## 촬영 조건과 기준값 해석 (자동 측정에서 확인한 사실)

- 사진은 4000 × 3000 으로 저장되고 EXIF 회전으로 세로(3000 × 4000)가 됩니다. `chc_5` 만 2380 × 3360 으로 잘려 있습니다.
- 매트는 바닥이 아니라 **벽 앞 막대에 집게로 매달아** 찍었고, 옷은 옷걸이에 걸었습니다. 그래서 용지 윗부분은 막대 위로 꺾이고 아랫부분은 말려 있어 한 평면이 아닙니다. 평면 호모그래피 하나로 맞추면 줄 간격이 중앙과 가장자리에서 10 % 가까이 차이 나므로, 표식 전체를 지나는 얇은 판 스플라인(TPS)으로 펴야 합니다.
- 조명이 위쪽에 있어 옷 아래와 옆에 2~10 cm 폭의 그림자가 종이에 집니다. 그림자를 옷으로 세면 기장이 길어집니다.
- 기준값 `h`는 줄자 '총장'이라 **깃을 뺀 어깨선~밑단**에 가깝습니다(외투 깃 끝~밑단은 65 가 아니라 약 70). 바지 `w=42` 는 고무줄로 오므라든 맨 윗줄(약 33)이 아니라 허리 아래 약 5 cm 의 폭과 맞습니다.
- 매달린 옷의 겨드랑이 폭은 펼쳐서 잰 값보다 작게 나옵니다(원피스 40 → 사진 33~37, 외투 55 → 49~52). 네 배경에서 값이 서로 비슷하므로 측정이 흔들린 것이 아니라 '매달림'과 '펼침'의 차이입니다. 다음 촬영은 매트를 바닥에 펴고 옷을 평평하게 놓는 것이 좋습니다.
- 흰 크롭티셔츠는 밝기·색이 종이와 같아서(상대 채도 2~5, 종이 자체 색 드리프트 4~16) 색으로는 구분되지 않고, 천 끝과 그림자 경계선으로만 윤곽을 잡을 수 있습니다.
