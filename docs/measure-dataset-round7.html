848px는 어떤 크기인가요? 기준판을 펼친 결과는 긴 변이 최대 848px인 동일 비율 이미지예요. 기존 서비스는 마스크 계산 전에 긴 변을 600px로 줄였고, 통합 방식은 원본에서 평판화한 뒤 그 재축소를 생략합니다. 원본이 더 작으면 확대하지 않아요.

저장된 7차 실험 결과를 불러오고 있어요.

비교한 두 가지 흐름

옷 종류별 결과

각 칸은 성공 장수, 너비 / 기장 평균 절대 오차(cm), 평균 처리 시간입니다.

배경별 결과

배경마다 옷 종류가 다른 사진 5장이 들어 있습니다.

사진별 측정값과 실패 기록

기준 치수, 각 방식의 측정값과 절대 오차를 확인할 수 있어요.

결과를 이렇게 읽었어요

    잰 너비와 기장으로 한국 아동복 호수를 매핑해요

    자동 측정된 너비와 기장을 옷 종류별 참고 치수표와 비교해 가장 가까운 호수를 바로 표시합니다. 점수는 너비·기장 차이를 각각 입력 치수로 나눈 뒤 평균해 계산하고, 점수가 가장 낮은 호수를 선택해요. 결과를 안내한 뒤 사용자가 호수를 직접 고칠 수 있습니다.

    상의 참고 호수너비기장
    90호28cm38cm
    100호30cm42cm
    110호32cm46cm
    120호34cm50cm
    130호36cm54cm
    140호38cm58cm
    150호41cm62cm
    160호44cm66cm
    점수 = (|기준 너비 - 잰 너비| / 잰 너비
      + |기준 기장 - 잰 기장| / 잰 기장) / 2
선택 호수 = 점수가 가장 낮은 기준 치수

    예를 들어 상의가 너비 34.5cm, 기장 50.5cm면 상의 참고표에서 120호(34 × 50cm)가 가장 가까운 후보가 됩니다. 원피스와 바지는 별도 기준표를 사용해요. 이 표는 안내용 참고값이며 KS 공식 의류 치수표나 모든 브랜드의 실측을 대표하지 않아요. 브랜드 상품 치수표와 아이에게 맞는지는 별도로 확인해야 합니다. 호수 매핑 기준과 전체 옷 종류별 표 보기

    모델 출처와 사용 조건
    실험에서 사용한 DeepFashion2 YOLO 모델 카드의 라이선스 표기와 내려받은 ONNX 파일의 메타데이터 표기가 서로 달라 추가 확인이 필요해요. 모델 파일은 저장소나 GitHub Pages에 올리지 않았습니다. 이번 공개 페이지는 알고리즘과 측정 결과를 기록하며, 모델 배포나 사용 권한을 단정하지 않습니다.

    같은 데이터셋으로 실험 방법을 선택하고 다시 비교했으므로 독립 검증은 아니에요. 사진 20장 결과는 실제 환경의 정확도를 보장하지 않습니다. 통합 흐름은 기장 오차를 낮췄지만 너비 오차와 처리 시간이 늘었고 1장이 실패했어요.
