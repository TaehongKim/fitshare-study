ROUND 6 · 너비를 재는 위치를 바꾸면 더 정확할까요?

티셔츠·원피스·점퍼의 너비선을 60%로 옮겼어요

통합 개선안의 848px와 치수별 분할은 그대로 두고, 옷 위에서 아래로 잰 너비선의 위치만 바꿨어요. 같은 20장 사진으로 기존 비율과 60%를 비교했습니다.

유지848px 사진 보정원본 비율과 기준판 무늬 환산
유지GrabCut + YOLO→GrabCut너비 분할과 기장 분할은 그대로
변경너비선 위치 60%크롭 티셔츠·원피스·점퍼만

어디에서 너비를 재나요?

옷의 위쪽 끝을 0%, 아래쪽 끝을 100%로 보고 너비선을 정해요. 아래 그림은 비교한 위치를 보여주는 예시예요. 파란 선은 실제 봉제선이나 겨드랑이를 검출한 선이 아닙니다.

target_y = width_top + (width_bottom - width_top) * 0.60

6차 실험 결과를 불러오고 있어요.

옷 종류별로 확인해요

각 칸은 성공 장수와 너비·기장 평균 절대 오차(cm)예요. 오차가 작을수록 줄자로 잰 기준에 가까워요.

사진별 측정값

사진을 보면서 기준 너비와 두 위치의 측정값을 확인할 수 있어요.

실제 서비스 설정
이 20장에서는 60%가 더 정확해지지 않았어요. 전체 너비 오차와 대상 옷의 너비 오차가 모두 커져, 실제 서비스는 검증된 통합 개선안 너비 비율을 유지합니다. 새 촬영 조건과 더 많은 옷으로 다시 검증하기 전에는 60%를 기본값으로 사용하지 않아요.

같은 20장 사진으로 비교한 결과라 독립 검증은 아니며, 다른 옷이나 촬영 환경에서도 같은 결과라고 단정할 수 없습니다. 이 실험에서는 너비선 위치 외에 사진 보정과 옷 분할 방법을 바꾸지 않았습니다.
