# 초등학생 추천 개발용 실제 상품 목록

## 현재 등록 형식 (2026-10-17 수정)

사진 출처만 실제 상품을 사용하며, 등록 정보는 기존 6벌과 같은 옷 등록 형식이다.
각 옷에 `garmentTypeId`, `ownerName`, `lengthCm`, `widthCm`, `photoUrl`, `closetPhotoUrl`, `createdAt`을 기록한다.
한 옷에는 120~160 중 하나의 사이즈와 숫자 길이·너비가 있다. 치수와 등록자 `체험 옷장`은 가상이며 `isDemo: true`, `measurementStatus: demo`로 명시한다.
실제 상품 실측표에서 가져온 값으로 해석하면 안 된다. 사진·상품 출처는 검증용 메타데이터로만 보존한다.
상세 화면·옷장·정보 수정·예약은 기존 등록 옷과 같은 흐름을 쓴다. 사진은 원본 JPEG, 옷장 PNG, 썸네일 PNG를 제공한다.
공급된 옷 단독 이미지를 그대로 PNG로 준비하며 실측용 GrabCut 또는 AI용 SAM을 실행한 것처럼 기록하지 않는다.
`python tools/import_school_catalog.py` 후 `powershell -NoProfile -File tools/prepare_demo_photos.ps1`로 로컬 이미지를 준비한다.
사진이 없는 삭제된 등록은 재생성하지 않는다. 이번 형식 수정 시 삭제된 3벌을 제외한 체험 21벌과 기존 6벌, 총 27벌을 유지했다.

2026-10-17 추천 고도화에서는 현재 남은 체험 옷을 계절별 상·하의 순서에 따라 호칭 130/140/150에 배치해 동일 사이즈·계절 조합을 4쌍에서 10쌍으로 보완했다. 스타일 3종, 상태 2종, 세부 종류·소매·바지 길이·두께·신축성·무늬도 추가했으며 이 속성들은 실제 판매 상품에서 검증한 물성값이 아닌 `metadataSources: demo` 가상 예시다.
기존 실제 6벌은 이름·등록자·실측·원본 사진을 유지하고 명확한 종류 힌트와 미등록 칸만 추가했다. `python -m tools.complete_legacy_metadata`로 해당 보완을 재현한다. 사이즈·계절·상태·소재 특성을 근거 없이 채우지 않으며 등록자/교사가 정보 수정에서 선택할 수 있다.

아래는 이전 카탈로그 방식의 수집 기록이며, 현재의 치수·예약 처리 기준은 위 내용을 따른다.

2026-10-17 유니클로 한국 공식 상품 페이지에서 계절별 상의 3종·하의 3종, 총 24종을 확인했다.
상품명·품번·대표 색상·사이즈·사진 출처는 `data/schoolCatalog.json`에 기록했다.
상품별 `sourceUrl`은 공식 상품 상세 페이지이며 `sourceImageUrl`은 공식 상품 사진이다.

| 계절 | 상의 | 하의 |
| --- | --- | --- |
| 봄 | 스트라이프 긴팔·코튼 긴팔·립 긴팔 | 저지 진·컬러 진·스웨트 팬츠 |
| 여름 | 프릴 반팔·코튼 반팔·그래픽 반팔 | 코튼 반바지·데님 쇼트 팬츠·데님 하프 팬츠 |
| 가을 | 스웨트셔츠 3종 | 배럴 진·스웨트 와이드 팬츠·카고 팬츠 |
| 겨울 | 니트 후리스·플러피 후리스·후리스 재킷 | 보아 팬츠·웜 라인 팬츠·웜 라인 데님 팬츠 |

모든 사진은 사람이 없는 옷 한 벌의 단독 사진으로 시각 검수했다. 대표 사진에 사람이 나온 여름 상품 3종은 공식 상세 사진 `sub14`로 교체했다.
검수한 이미지의 SHA-256과 출처를 `data/schoolCatalogImageReviews.json`에 기록했다. 다운로드 도구는 사진이 바뀌면 기존 검수 사진을 덮어쓰지 않는다.
이전에 추가한 착용 사진 포함 20벌은 `server-data/backups/retail-catalog-20-before-flatlay.zip`에 백업하고 등록 목록과 폴더에서 삭제했다.

- 실제 나눔 등록 옷이 아닌 상품 카탈로그 참고 자료다. 매장별 재고나 구매 가능 여부는 보장하지 않는다.
- `availableSizes`는 공식 사이트의 사이즈 표기 중 120~160 범위다. 품절 여부와 별개다.
- `lengthCm`, `widthCm`은 실측표를 확인하지 못해 null이다. 숫자로 대체하거나 실제 측정값으로 취급하지 않는다.
- `season`, `style`은 추천 개발을 위한 편집 분류다. 판매처가 확인한 분류와 구분한다.
- 성별은 추천 대상을 제한하지 않기 위해 공용으로 처리한다. 제조사의 성별 표기를 나타내지 않는다.
- 중고 옷 상태는 확인할 수 없어 `condition`을 미확인으로 기록했다.
- 추천 점수의 기존 가중치는 유지했다. 사이즈 점수는 판매 사이즈 존재 여부이며, 착용 적합성의 검증 결과가 아니다.
- 추천 탭은 `/api/garments`에 남아 있는 상품만 읽는다. 교사가 옷을 삭제하면 카탈로그 원본 JSON에 남아 있더라도 추천 후보에서 제외한다.

`python tools/import_school_catalog.py`는 같은 상품을 중복 추가하지 않고 카탈로그를 갱신한다.
`python tools/download_catalog_photos.py`는 공식 JPEG 사진을 각 상품 폴더에 저장한다. 추가 패키지를 사용하지 않는다.
사진 권리는 원 판매처에 있다. 공개 배포 시 사진 이용 조건을 별도로 확인한다.

기존 `[가상] 체험용` 30벌은 삭제했으며, 원본은 `server-data/backups/virtual-garments-20261017-162326.zip`에 보관했다.
실측 사진이 있는 기존 6벌은 유지했다. 추천 탭의 예전 가상 예시 5벌 대신 이 카탈로그를 사용한다.
