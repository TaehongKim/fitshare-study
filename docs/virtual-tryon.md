# 가상 입어보기

추천 카드와 학교 옷장 카드·옷 상세창의 **가상으로 입어보기**로 한 벌을, 세트 결과의 **이 세트 가상으로 입어보기**로 상의와 하의를 함께 선택한다. 등록 화면의 옷 목록에도 같은 버튼이 있다. 지원 종류는 상의·하의다. 옷 사진을 준비한 다음 **카메라 켜기**를 누르고 권한을 허용한다. 상의는 양어깨, 하의는 골반이 화면에 보이게 서고, 조절할 옷을 선택해 전체 크기와 좌우·위아래 위치를 맞춘다. **사진 저장**을 누르면 브라우저에서 PNG를 내려받는다.

## 지금 사용하는 표시 방법

배경을 제거한 옷 사진 한 장을 통째로 몸 위에 겹친다. 상의는 양어깨, 하의는 양쪽 골반을 기준으로 위치와 회전을 정하고, 가로·세로에 같은 배율을 적용한다. 옷을 몸통·소매·바짓가랑이로 잘라 나누거나 팔꿈치·손목·무릎을 따라 휘지 않는다. 사진에 남아 있는 소매 끝과 무늬, 상하 비율을 그대로 유지하는 방식이다.

MediaPipe는 신체 위치를 찾는 데 사용한다. 모델이 다른 관절 좌표도 출력하지만, 옷을 팔과 다리 관절에 맞춰 변형하는 데 사용하지 않는다. 사용자가 팔을 구부려도 사진 속 소매는 사진에 찍힌 모양을 유지한다. 손목이 화면 밖으로 나가더라도 그것을 이유로 소매 부분을 삭제하지 않는다.

이 방식을 고른 이유는 한 장의 사진에서 접힌 소매와 가려진 옷감을 정확히 알 수 없기 때문이다. 부위를 나눠 억지로 움직이는 과정에서 생기던 잘림·늘어남을 줄이고, 사용자가 선택한 실제 옷의 모양을 보여 주는 데 집중한다. 대신 팔의 움직임이나 몸의 굴곡에 맞는 자연스러운 착용 모습은 표현하지 못한다.

## 옷 사진에서 배경을 지우는 방법

`GET /api/garments/:id/tryon-photo`는 등록 원본을 다시 읽는다. 매트 사진은 보정한 원본에서 시작하며 예전에 잘린 옷장 마스크를 재사용하지 않는다. YOLO로 옷 위치를 찾고, 단색 배경은 사진 가장자리와 연결된 배경부터 제거한다. 복잡하거나 불확실한 배경은 소매의 작은 전경 씨앗을 보호하면서 GrabCut으로 경계를 보정한다. 코드는 `tools/tryon_segmentation.py`에 분리했다.

긴바지 양다리와 반바지를 지원하며, 빈 마스크나 거의 전체 이미지인 마스크는 거부한다. 입어보기용 사진을 등록 정보·실측·원본 사진에 덮어쓰지 않는다. 옷 등록 실측과 AI 상품 사진 생성의 분할 알고리즘은 변경하지 않았다.

통째로 표시하는 방법도 배경 제거에서 이미 사라진 소매를 되살리지는 못한다. 원본에서 보이지 않는 옷감이나 무늬를 새로 만들지 않는다. 옷 사진 자체가 접혀 있으면 접힌 모습 그대로 보인다. 옷이 화면 가장자리를 넘으려 하면 전체 크기와 위치를 자동으로 보정한다. 이때 옷 전체를 보여 주기 위해 몸의 기준 위치에서 조금 옮겨지거나 작아질 수 있다. 전체 크기와 위치를 직접 조절하거나 카메라에서 조금 뒤로 서면 맞추기 쉽다.

## 코드와 카메라 관리

- 사용자 지정 원본은 `C:\Users\mello\OneDrive\바탕 화면\코드페어_결선`이며 원본 폴더는 수정하지 않았다. 현재 표시는 그 프로젝트에서 가져온 소매 메쉬 방식 대신 전체 사진을 변환하는 방식을 사용한다.
- `js/virtualTryOn/fit.js`는 옷 전체의 배율·위치·회전을 계산한다. 같은 배율로 가로·세로를 조절해 원본 비율을 유지한다.
- `vision.js`는 MediaPipe Tasks Vision 0.10.14의 PoseLandmarker를 준비한다. GPU 초기화 실패 시 CPU로 재시도하며 모델·WASM을 CDN에서 내려받는다. `filters.js`는 신체 기준점의 떨림을 줄인다.
- `index.js`는 옷 ID로 최신 정보와 투명 PNG를 조회하고 다이얼로그·카메라·조절·저장을 관리한다. 같은 종류 두 벌은 세트로 열지 않으며 삭제된 옷과 사진 오류를 안내한다.

카메라는 사용자가 명시적으로 켜기를 눌렀을 때만 요청한다. 오디오를 요청하지 않으며 localhost 또는 HTTPS에서 사용한다. 영상은 브라우저에서 처리하고 서버에 저장하거나 전송하지 않는다. 닫기·탭 이탈·페이지 숨김·연결 종료 시 트랙과 프레임 루프를 정리한다. 옷장 카드나 상세창의 연결·숨김·열림 상태를 감시하므로 목록 갱신·페이지 넘김·상세창 닫기 때도 종료한다. 닫힌 후 도착한 카메라 스트림도 즉시 종료하고 모델 객체를 해제한다. 카메라 거부·모델 다운로드 실패는 안내 후 재시도할 수 있다.

이는 옷 사진을 몸에 겹쳐 보는 참고 기능이다. 실제 사이즈·착용감이나 3D 의상 시뮬레이션을 제공하지 않는다.

## 확인 방법과 기존 배경 제거 결과

- `python -m unittest tests.test_tryon_segmentation tests.test_tryon_photo`: 밝은/어두운 배경, 얇은 소매, 내부 무늬, 양쪽 바짓가랑이, 잘못된 이미지, 원본 보존과 API를 검사한다.
- `/tests/virtual-tryon.html`: 옷 표시와 세트 전달, 명시적 카메라 시작, 트랙·모델 해제, 권한 거부, 늦은 응답, 삭제 옷, 탭 이탈 경로를 검사한다.
- `/tests/closet-tryon.html`: 옷장·상세의 버튼 연결, 지원 종류, 요청 ID, 새로고침·페이지 이동·숨김·상세 종료 시 정리를 검사한다.
- `/tests/tryon-model-smoke.html`: 실제 다운로드한 모델로 빈 캔버스 추론을 검사한다. 이 검사만으로 사람이 움직일 때의 표시 품질을 평가할 수는 없다.
- 기존 배경 제거 비교에서 체험 사진 21벌 중 20벌은 가장자리 배경 연결, 1벌은 보호 GrabCut으로 준비했다. 기존 실제 상·하의 5벌도 원본·매트 보정·이미지 준비 경로를 확인했다. 이 수치는 사진 준비 결과이며, 현재 전체 사진 표시나 실제 착용의 정확도 점수가 아니다.
- `python -m tools.evaluate_tryon_quality`로 기존 배경 제거 전후 비교와 정답이 있는 합성 사진 평가를 재현한다. 실제 옷 사진에는 수작업 정답 마스크가 없어 픽셀 증가를 정확도로 표현하지 않는다.

초등학생용 최종 학습·발표 자료는 [가상입어보기-개선보고서.html](가상입어보기-개선보고서.html)이다. 핵심 7장, 변경 과정, 모델 역할과 선택 이유, 원리 설명 그림, 약 2분 발표 대본과 예상 질문을 담았다. ‘한 장씩 발표하기’에서 이전·다음 또는 키보드 화살표로 이동하며 Esc로 전체 내용에 돌아온다. 자세한 기록과 공식 근거는 접이식이고, 사진을 포함한 단일 HTML이라 오프라인에서도 열린다. `tools/templates/tryon_report.html`을 수정한 뒤 `python -m tools.build_tryon_report`로 비교 사진을 포함해 재생성한다. 실제 사람의 카메라 움직임에 대한 품질은 사용자가 카메라를 허용해 별도로 확인해야 한다.
