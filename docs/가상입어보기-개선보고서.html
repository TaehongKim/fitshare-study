배경이 남고, 소매가 사라졌어요

이미 소매가 잘린 옷장 사진을 다시 사용하면, 사진을 크게 늘려도 소매는 돌아오지 않았어요.

그래서 등록한 원본 사진부터 다시 읽고, 옷이 있는 곳과 배경을 함께 살피도록 고쳤어요.

같은 체험 상품 사진의 배경 제거 비교예요. 파란 부분은 투명한 배경을 알아보기 쉽게 칠한 색이고, 소매를 새로 그린 결과는 아니에요.

① 만든 이유

② 처음 문제와 수정
처음에는 배경이 남거나 소매가 사라졌습니다. 이미 잘린 사진을 다시 쓰면 소매가 돌아오지 않아서, 등록한 원본 사진부터 다시 처리하도록 바꿨습니다.

③ 모델의 역할과 선택 이유
옷 영역은 YOLO 계열 모델이 찾습니다. 단순한 배경은 가장자리와 연결된 부분부터 지우고, 어려운 경우에는 GrabCut으로 경계를 다듬습니다. 사람의 어깨와 골반은 MediaPipe Full 모델이 찾습니다. 필요한 위치 정보를 주고 기존 프로그램에서 실행되는 모델을 재사용했습니다. 저희가 모델을 새로 훈련한 것은 아닙니다.

④ 방법을 바꾼 이유
처음에는 소매를 나눠 팔에 맞추려 했지만, 어깨가 잘리거나 옷 모양이 달라졌습니다. 사진 한 장만으로 가려진 옷감을 알기 어려웠습니다. 그래서 최종적으로 투명한 옷 사진을 스티커 한 장처럼 통째로 보여 주기로 했습니다.

⑤ 완성한 방식
상의는 어깨에, 하의는 골반에 맞추고, 가로와 세로를 같은 비율로 바꿉니다. 화면 밖으로 나가지 않게 크기와 위치를 조절합니다. 팔을 구부려도 소매 모양은 사진 그대로이고, 몸을 옮기면 옷 전체가 따라갑니다.

⑥ 확인과 배운 점
체험용 실제 상품 사진 21장과 모의 카메라로 옷 전체가 남는지 확인했습니다. 하지만 실제 사이즈와 착용감을 보장하지는 않습니다. 이번 개발을 통해, 기능을 많이 넣는 것보다 문제를 확인하고 목적에 맞는 방법을 선택하는 것이 중요하다는 것을 배웠습니다.

발표 뒤에 나올 수 있는 질문 8개

AI를 직접 만들었나요?

이미 학습된 공개 모델을 사용했어요. 모델 결과를 연결하고, 배경을 정리하고, 옷을 표시하고, 카메라를 켜고 끄는 프로그램을 구현했어요.

왜 AI 모델을 두 개 쓰나요?

옷 사진에서 ‘어디가 옷인지’ 찾는 일과 사람 영상에서 ‘어디가 어깨인지’ 찾는 일이 달라서예요. YOLO는 옷 영역, MediaPipe는 사람의 기준점을 맡아요.

왜 MediaPipe Full을 골랐나요?

웹에서 몸 위치를 구할 수 있고, 가져온 코드에서 쓰던 Full 모델이 현재 브라우저에서도 실행되는 것을 확인했기 때문이에요. Lite·Full·Heavy를 같은 조건으로 비교한 결과는 없으므로 Full이 가장 빠르거나 정확하다고 말하지 않아요.

왜 소매가 팔을 따라 구부러지지 않나요?

소매를 나누고 휘는 과정에서 잘림과 변형이 생겨, 옷의 전체 모양 보존을 우선했기 때문이에요. 몸의 위치와 기울기가 바뀌면 옷 전체는 따라가요.

흰 배경은 그냥 흰색만 지우면 안 되나요?

흰 옷도 함께 지울 수 있어요. 그래서 옷 위치와 사진 가장자리에서 이어지는 배경을 함께 살펴봐요. 복잡하거나 판단이 어려우면 보호할 옷 부분을 표시해 GrabCut을 사용해요.

GrabCut·OpenCV·PNG도 AI 모델인가요?

GrabCut은 앞과 뒤를 나누는 계산 방법, OpenCV는 사진 처리 도구 모음, PNG는 투명한 배경을 저장할 수 있는 그림 파일 형식이에요. 모두 새로 학습한 AI 모델이라는 뜻은 아니에요.

화면에서 맞아 보이면 실제 몸에도 맞나요?

실제 치수와 착용감은 따로 확인해야 해요. 크기 조절은 화면 위 그림의 크기를 바꾸는 것이며, 몸과 옷의 실제 cm를 맞춰 계산한 결과가 아니에요.

가장 좋은 알고리즘이라고 말해도 되나요?

현재 사진과 목적에 맞춰 선택했다고 말해요. 모든 모델과 모든 사람·배경에서 비교한 실험은 없어요. 다음에는 다양한 배경과 체형, 학교 기기에서 잘림·인식 실패·처리 시간을 같은 기준으로 비교하고 싶어요.

사진에 이미 투명한 배경이 있으면 옷 찾기와 배경 제거를 다시 하지 않고 사용할 수 있어요. 옷 등록 실측과 AI 상품 사진 생성은 별도 기능이며, 현재 가상 입어보기와 같은 파이프라인이라고 설명하지 않아요.

카메라 영상과 옷 사진은 어디서 처리하나요?

옷 사진 정리: 이 프로그램의 Python 서버에서 원본 사진을 읽고 배경을 정리해요.

카메라 영상: 브라우저에서 몸 위치를 찾고 옷을 겹쳐요. 현재 코드에는 카메라 영상을 서버에 저장하거나 보내는 처리가 없어요. 카메라 켜기를 누를 때만 시작하고, 모델을 처음 내려받을 때는 인터넷이 필요해요. 사진 저장 버튼은 브라우저에서 PNG를 내려받아요.

선생님·개발자 참고: 모델 출처와 재현 경로

옷 모델 배포 경로는 HasanKabir23/Yolov26s-DeepFashion2의 best.onnx예요. 공개 카드와 같은 파일의 내부 메타데이터에 모델 크기·학습 데이터 설명 차이가 기록되어 있어, 본문은 ‘공개 YOLO 계열 옷 영역 모델’이라고 표현했어요. 특정 학습 자료와 세부 모델명을 확정한 설명은 하지 않아요. 이 차이는 프로젝트 experiments/garment_ai/README.md와 results/report.md에 기록돼 있어요.

카메라는 @mediapipe/tasks-vision@0.10.14와 pose_landmarker_full/float16을 사용해요. 라이브러리 버전은 고정되어 있지만 모델 주소에는 latest가 있어요. GPU 초기화가 실패하면 CPU로 다시 준비해요. 성능 순위를 비교한 결과는 아니에요.

현재 코드: tools/tryon_photo.py, tools/tryon_segmentation.py, js/virtualTryOn/fit.js, vision.js, filters.js, index.js.

배경 비교 재현: python -m tools.evaluate_tryon_quality. 배경/API 검사: python -m unittest tests.test_tryon_segmentation tests.test_tryon_photo. 화면 검사: tests/virtual-tryon-anatomy.html?inventory=1, tests/virtual-tryon.html, tests/closet-tryon.html. 문서 재생성: python -m tools.build_tryon_report.

예전 옷 실측 실험의 cm 오차나 분류율을 현재 가상 입어보기 성능으로 옮겨 적지 않았어요. 위 검사 수는 2026년 10월 18일까지의 기록이며, 이 문서를 열 때 검사가 다시 실행되는 것은 아니에요.
