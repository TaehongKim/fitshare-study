# 교사 권한과 AI 상품 사진 설계

## 목표

회원가입 때 교사 인증 코드를 확인해 교사·학생 계정을 나누고, 교사만 기존 옷 사진의 AI 상품 이미지 생성, 교사 인증 코드 변경, 학생 비밀번호 재설정을 할 수 있게 한다.

## 기본 정책

- 새 가입은 기본 학생 계정이다. 교사 가입은 서버가 관리하는 현재 인증 코드와 입력값이 일치할 때만 허용한다. 초기 인증 코드는 사용자가 지정한 `fitshare`다.
- 기존 계정 레코드에 역할이 없으면 학생으로 취급한다. 가입 응답·로그인 응답·`/api/auth/me`에는 `username`, `name`, `role`만 반환한다.
- 역할 판정은 매 API 요청에서 서버가 로그인 세션과 계정 저장 파일을 기준으로 수행한다. 브라우저에 있는 역할 표시나 요청 본문만으로 권한을 인정하지 않는다.
- 교사 인증 코드는 영속 파일에 해시로 저장한다. 최초 파일이 없을 때만 `fitshare`를 초기값으로 사용한다. 인증 코드를 바꾸면 이후 신규 교사 가입부터 새 값을 요구하며, 이미 등록된 교사 권한은 유지한다.
- 교사는 자기 프로필에서 새 인증 코드를 설정할 수 있다. 학생은 코드 변경 API를 호출해도 거부된다. 코드 자체를 화면에 다시 표시하지 않는다.
- 교사는 학생 아이디를 지정해 새 비밀번호를 설정한다. 학생 외 계정이나 존재하지 않는 계정에는 변경을 허용하지 않는다. 재설정된 학생의 기존 세션은 모두 폐기한다.
- 모든 기존 비밀번호 해시는 그대로 사용한다. 평문 비밀번호나 교사 인증 코드는 로그에 남기지 않는다.

## AI 상품 사진

- 교사는 옷장에 등록된 옷 상세 화면에서 기존 사진으로 AI 상품 이미지 생성을 시작한다. 학생 화면에는 생성 동작을 제공하지 않고, 서버도 같은 권한을 강제한다.
- Replicate 호출은 서버에서만 수행하며 현재 설정 패턴의 `REPLICATE_API_TOKEN`을 사용한다. 브라우저에 토큰을 전달하지 않는다. 서비스용 모델은 프로젝트 실험에서 선택된 Qwen Image Edit Plus로 고정하고, 모델 버전 식별자는 서버 설정으로 둔다.
- 생성된 사진은 원본 업로드 사진과 분리해 저장하고 기존 옷 레코드에 생성 사진 경로와 상태를 추가한다. 생성 실패·모델 응답 오류는 원본이나 옷 레코드를 손상시키지 않는다.
- AI가 옷의 실제 색상·무늬·형태를 바꿀 수 있으므로, 옷 정보를 확인하기 위한 원본 사진은 계속 볼 수 있게 한다. 생성 결과는 상품 보기용 참고 이미지로 표시한다.
- 모델 버전이나 토큰이 설정되지 않은 경우, 교사에게 설정 부족을 설명하고 원본 기능을 계속 사용할 수 있게 한다.

## 화면과 API 경계

- `index.html`, `js/app.js`: 가입 폼의 선택적 교사 코드 입력과 교사 배지/프로필 접근 연결을 추가한다. 학생 가입은 코드 없이 가능하다.
- `js/auth.js`: 가입 시 선택된 교사 코드 전달과 서버가 돌려준 역할 보관을 지원한다.
- `modules/profile.js`: 교사 인증 코드 변경과 교사 전용 학생 비밀번호 재설정 UI를 제공한다.
- `modules/garmentDetail.js`: 교사 전용 AI 상품 사진 생성, 진행/오류 표시, 원본·생성본 전환을 제공한다.
- `server.py`: 인증, 코드 설정, 비밀번호 재설정, 상품 이미지 생성 API에서 교사 권한을 확인한다.
- `tools/accounts.py`: 역할 필드, 교사 코드 해시, 역할 반환, 코드 변경 및 학생 비밀번호 초기화를 담당한다.
- `tools/replicate_product_photo.py` (신규): 기존 Replicate 표준 HTTP 패턴으로 이미지 파일 전송·편집·결과 저장을 담당한다.
- `tests/test_ranking_api.py` 또는 `tests/test_accounts.py` (신규): 가입 역할, 역할 위조 차단, 코드 변경, 학생만 비밀번호 재설정, 세션 폐기, 상품 생성 권한을 검사한다.
- 기존 프로필·상세 화면 테스트에 학생/교사 표시와 생성 결과 상태를 추가한다.

## 오류 및 보안 처리

- 비로그인 요청은 인증이 필요한 작업에서 거부하고, 학생의 교사 전용 요청은 403을 돌려준다.
- 잘못된 교사 코드로 가입하면 계정이나 세션을 만들지 않는다.
- 비밀번호 재설정은 요청 본문의 역할을 무시한다. 기존 로그인 실패 제한과 PBKDF2 저장 규칙을 동일하게 적용한다.
- 외부 이미지 편집 실패 시 사용자에게 이해 가능한 메시지를 돌려주고, 임시 파일과 업로드한 Replicate 파일을 가능한 경우 정리한다.
- 생성 사진·원본 사진은 `server-data/` 아래에 두고 Git에는 포함하지 않는다.

## 제외와 후속 설정

- 교사 계정의 이메일·전화번호 복구, 다중 학교별 인증 코드, 사용량 과금 UI는 범위에 없다.
- 배포 전에 Replicate의 Qwen Image Edit Plus 모델 버전을 서버 환경에 설정해야 한다. 이 프로젝트의 기존 `REPLICATE_API_TOKEN`이 이미지 편집 호출 권한을 갖는지 확인한다. 프로젝트 실험에서 안내한 예상 요금은 이미지 한 장당 약 US$0.03이므로, 교사가 옷마다 생성 요청을 누를 때만 호출한다.
