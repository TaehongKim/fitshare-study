# 국내 아동복 호수 자동 매핑 설계

## 목표

사진으로 잰 옷의 너비와 기장을 국내 아동복에서 쓰이는 키 호수(예: 90, 100, 110) 중 하나로 자동 매핑한다. 사용자는 결과를 직접 수정할 수 있다. 현재의 상품별 치수표 직접 비교도 남긴다.

## 기준과 한계

- KS의 아동복 치수 체계에서 호수 숫자는 아이의 키를 나타내는 이름으로 사용된다.
- KS 기준은 사진으로 잰 옷의 펼친 너비와 기장만으로 호수를 판정하는 공식 변환표를 제공하지 않는다.
- 따라서 프로그램은 상의/하의 종류별 참고 치수표에 입력값을 대조해 가장 가까운 호수 하나를 기본 선택한다.
- 이 매핑은 KS 공식 판정이나 착용 적합성 보장이 아니며, 브랜드별 차이가 있음을 결과와 설명에 알린다.

## 동작

1. 옷 종류와 측정 너비·기장을 선택/입력한다.
2. 해당 종류의 내장 참고표에서 너비·기장 오차를 함께 비교해 가장 가까운 국내 호수를 자동 선택한다.
3. 호수 선택 컨트롤에서 사용자가 직접 다른 호수로 바꿀 수 있다.
4. 기존 상품별 치수표 비교는 별도 수동 비교 수단으로 유지한다.
5. 잘못되거나 빠진 치수에는 이해하기 쉬운 오류 안내를 보여 준다.

## 변경 범위

- `docs/measurement-process.html`: 자동 매핑 입력·결과·수정 UI와 설명 업데이트.
- `docs/js/measurement-size-matcher.js`: 종류별 참고표 매핑과 수동 호수 변경 처리.
- 기존 관련 테스트에 자동 선택, 경계/오류 입력, 수동 변경 사례를 보강한다.
- 다른 측정 모듈은 수정하지 않는다.

## 검토 메모

내장 참고 치수값은 KS의 공식 옷 치수표라고 표현하지 않는다. 코드와 화면 설명에 참고용으로 명시하고, 호수는 아이 키 기준의 국내 표기 체계를 따른다.
