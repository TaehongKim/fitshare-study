# 학교 옷장 입장과 ChArUco 옷 등록 설계

## 목표

학교 코드 `대전서원초등학교`를 입력한 뒤 사용자가 실제 다음 행동을 찾지 못하는 문제를 고치고, 메인 화면에서 M4 ChArUco 교차점 매트를 쓰는 옷 등록 화면으로 이어지게 한다. 등록 화면은 사진에서 옷의 종류, 기장, 너비, 대표 색을 찾아 제안하고, 사용자가 확인하거나 고친 뒤 서버 PC에 저장한다.

## 현재 확인한 문제와 기반

- `js/app.js`는 빈 값만 막고 성공 문구를 표시한다. 모듈 카드가 아래에 있지만 입장 뒤 `scrollIntoView({ block: 'center' })`가 페이지를 예상 밖 위치로 움직인다.
- `modules/measurement.js`는 M1~M4 비교 실험 링크만 제공한다. 옷 등록 작업으로 가는 버튼은 없다.
- `measure_pipeline/`에는 M4 표식 지도, 이미지 평판화, 옷 분할, 상의/바지 치수 측정 코드가 있다. 5벌·20장 샘플에서 M4 결과가 측정 성공했지만, 일반 옷 전반의 정확성을 보장하는 자료는 아니다.
- 현재 데이터에는 옷의 남성용/여성용 라벨이 없다. 옷 사진만으로 판매 대상 성별을 과학적으로 판정할 근거가 없으므로 남/여를 자동 확정하지 않는다. 이 버전은 사용자가 직접 남성용·여성용·공용·모름 중 확인하게 하고, 분류 모델은 라벨이 있는 충분한 학습 사진을 모은 뒤 별도 작업으로 다룬다.

## 사용자 흐름

1. 메인 화면에 학교명을 입력하고 Enter 또는 입장 버튼을 누른다.
2. 입장 완료 메시지와 함께 분명한 `옷 등록 시작` 버튼이 보인다. 성공만 표시하고 화면 가운데로 강제 이동하는 동작은 없앤다.
3. 등록 화면에서 옷 한 벌의 사진을 갤러리에서 고르거나 카메라로 찍는다. 화면은 M4 ChArUco 교차점 매트만 안내한다.
4. 분석 서버가 매트를 찾아 사진을 평판화하고, 옷 영역·기장·너비·대표 색을 제안한다. 옷 종류도 외곽 형태 기반으로 후보를 제안하되, 낮은 확신도는 `직접 선택`으로 표시한다.
5. 학생이 사진과 자동 입력값을 확인·수정한다. 용도는 `남성용 / 여성용 / 공용 / 모름` 중 직접 선택한다.
6. 저장하면 사진과 확인된 정보가 서버 PC의 `server-data/garments/`에 남고, 등록된 옷 목록에서 다시 볼 수 있다.

## 분석 및 저장 규칙

- 등록 API는 `ChaArUco_Cross`(M4)만 허용한다. 다른 배경 ID는 오류를 돌려준다.
- 분석 결과는 입력 제안일 뿐이며 저장 전 검토가 필수다. 자동 결과는 사진 미리보기와 함께 편집 가능한 입력란에 넣는다.
- 색은 분할된 옷 영역의 대표색으로 계산한다. 검정/흰색/회색 계열과 기본 색 이름을 보여준다.
- 크기 분석에는 `measure_pipeline`의 ChArUco 교차점 평판화와 옷 마스크·측정선을 사용한다. 분석 실패 시 이해하기 쉬운 오류를 보여주고, 사진 또는 입력값을 다시 고를 수 있다.
- 옷 종류 자동 후보는 현재 다섯 샘플만으로 제한된 규칙 기반 제안이며 확정값으로 취급하지 않는다. 남성용/여성용 추론은 라벨 데이터가 없으므로 수행하지 않는다.
- 저장은 Python 표준 라이브러리 서버와 JSON/JPEG 파일을 이용한다. npm, 프레임워크, DB는 추가하지 않는다.

## 테스트 및 완료 조건

- 메인 입장: 한국어 학교명, 앞뒤 공백이 있는 학교명, 빈 입력, Enter 입력에서 다음 화면 CTA의 표시를 확인한다.
- 분석: M4 정상 사진에서 치수와 색 후보 반환, 잘못된 이미지와 M1~M3 입력 거부, 분석 실패 시 저장되지 않음을 확인한다.
- 저장: 필수 항목 누락 거부, 남녀·공용·모름 선택 저장, 사진과 JSON 재조회, 잘못된 파일명/ID 거부를 확인한다.
- 전체 Python 테스트 및 화면 모듈 문법/동작 테스트를 통과한다.
- 실제 브라우저에서 화면을 열어 입력-분석-수정-저장을 확인한다. 데이터셋 5벌을 넘는 품질과 성별 판정은 별도 라벨 자료 없이 완료로 주장하지 않는다.

## 영향 범위

공통 메인 진입과 실측 모듈만 변경한다. 추천·랭킹 모듈, 기존 실험 회차 및 결과 페이지는 변경하지 않는다.

## 2026-10-09 파이프라인 통일 보완

옷 등록 분석은 실험과 같은 `tools.vision_pipeline.rectify_photo(photo, "M4")` 및 `measure_garment(flattened["image"], garment_id=...)`를 호출한다. 등록 화면에서 옷 종류 1~5를 먼저 고르는 이유는 실험과 동일한 종류별 측정 프로필을 선택하기 위해서다. 15cm보다 짧은 기장처럼 옷 전체를 찾지 못한 결과는 유효한 값으로 저장하지 않고 다시 촬영하도록 안내한다.
