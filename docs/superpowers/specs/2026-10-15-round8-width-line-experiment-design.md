# 8차 너비선 60% 비교 실험

## 목적

검출한 옷 영역의 위쪽에서 60% 내려온 곳을 티셔츠, 원피스, 점퍼의 너비선으로 사용하면 기존 위치보다 줄자 기준값에 가까워지는지 확인한다.

## 비교 방법

- 같은 20장과 848px 보정 이미지를 사용한다.
- 사진 보정, 너비용 GrabCut, 기장용 YOLO→GrabCut, 픽셀 환산 및 기장 계산은 7차와 동일하게 둔다.
- 대조군은 7차의 기존 너비 비율(티셔츠 32.5%, 원피스 15%, 점퍼 20%)을 명시적으로 적용한다.
- 후보군은 세 옷 종류에 60%를 적용한다. 상의 외투와 바지의 위치는 대조군과 같은 값을 쓴다.
- 전체 20장과 대상 12장을 각각 집계하고, 사진별 값·실패·시간을 JSON과 HTML에 기록한다.

## 실제 서비스 적용 결정

60% 후보가 오차를 낮추면 재검토할 수 있으나, 결과가 나빠지면 서비스 기본값은 7차로 유지한다. 실험용 비율은 재현 runner에서만 사용한다. 결과 페이지에는 표본 수와 이 적용 결정을 설명한다.

## 확인

- 정상: 비율 60%가 옷 높이의 60% 위치로 환산된다.
- 경계: 0 이하, 1 이상, 잘못된 비율은 거부한다.
- 오류: 측정 실패는 결과 행에 남고 성공 MAE 계산에서 제외한다.
- 공개: 8차 HTML, JS, CSS, JSON과 실험 목록 링크를 `yunchae` Pages에서 확인한다.
