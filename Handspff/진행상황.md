## 실행과 확인

1. 프로젝트 폴더에서 `python server.py`로 실행한다. 기존 `python -m http.server 8000`은 API를 지원하지 않는다.
2. PC에서는 `http://localhost:8000/`, 같은 Wi-Fi의 휴대폰에서는 `http://192.168.99.16:8000/`으로 접속한다. 휴대폰 회차 목록 주소는 `/results/sessions.html`이다.
3. 사진은 서버 PC의 `server-data/experiments/` 아래에 보관된다. 이 폴더를 Git에 올리지 않는다.

## 2026-10-09 HEIC 사진 형식 안내

- 사진 읽기 오류 문구가 `js/measurement/photoImage.js`에서 나오는 것을 확인했다. HEIC/HEIF를 `accept` 목록으로 고를 수 있게 해 두었지만, 브라우저 디코더가 지원하지 않으면 JPG/PNG 안내로 실패하는 구조였다.
- ImageBitmap과 HTML Image가 모두 파일을 열지 못한 경우 MIME과 파일 헤더를 확인해 HEIC/HEIF용 변환 안내를 표시한다. HEIC 외 지원되지 않는 형식에는 기존 JPG/PNG 안내를 유지한다.
- `tests/measurement-photo-image.html`에 HEIC 헤더 경로를 추가했다. 이미지 로딩 JS 테스트 5개 및 관련 JS fixture 총 38개, 서버 테스트 6개가 통과했고, 로컬 HTTP 응답도 확인했다.
- HEIC 디코더나 변환기는 추가하지 않았다. 브라우저가 디코딩할 수 없는 HEIC는 사진 앱/기기에서 JPG로 변환해야 한다.
