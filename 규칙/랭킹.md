# 🏆 참여 랭킹 규칙
담당 파일: `modules/ranking.js`

## 처음 정한 규칙
```
기부한 사람이 1점
받은사람1점
1달마다 랭킹초기화
하루 최대 3점
받은거 다시 나눔금지
```

## 규칙 정리
| 규칙 | 뜻 |
|------|----|
| 준 사람 +1점 | 옷 1벌을 주면 1점 |
| 받은 사람 +1점 | 옷 1벌을 받으면 1점 |
| 1달마다 초기화 | 이번 달 기록만 셈. 매달 1일에 0점부터 |
| 하루 최대 3점 | 한 사람이 하루에 받는 점수는 3점까지 |
| 다시 나눔 금지 | 받았던 옷을 또 나누면 점수 없음 |

- 점수가 같으면 같은 등수예요. (1등, 2등, 2등, 4등)
- 규칙에 안 맞는 기록은 "점수에 안 들어간 기록"에 이유와 함께 보여 줘요.
- 도우미 **토리 🐿️**가 내 순위, 오늘 남은 점수, 초기화까지 남은 날을 알려 줘요.

## 예시 (10월 가상 기록)
- 10/2 하늘이가 4명에게 나눔 → 하늘이는 3점에서 멈춤
- 10/7 새싹이가 9월에 받은 옷을 나눔 → 점수 없음
- 결과: 🥇 하늘이 5점 · 🥈 꼬마별, 새싹이 4점

## 테스트
| 종류 | 상황 | 결과 |
|------|------|------|
| 정상 | 가상 데이터 | 하늘이 1등, 꼬마별·새싹이 공동 2등 |
| 경계 | 하루에 4번 나눔 | 3점에서 멈춤 |
| 오류 | 날짜·이름이 빈 기록 | 빼고 앱은 그대로 동작 |

## 🤔 팀이 확인할 것
- [ ] 하루 3점은 준 점수 + 받은 점수를 **합쳐서**인가요?
- [ ] 받은 옷을 다시 나누면 **받은 사람도** 0점인가요?
- [ ] 랭킹은 **개인별**(지금)인가요, **반별**인가요?
