# 👕 맞춤 추천 규칙 — AI가 잘 입은 옷 따라 하기
담당 파일: `modules/recommendation.js`

## 0. 처음 정한 규칙
```
ai가 잘 입은 옷 따라하기
```
→ **잘 입은 코디 예시**를 모아 두고, AI가 그 예시를 보고 **내 옷장에서 비슷한 옷을 골라** 추천해요.

---

## 1. 실제로 쓰는 순서 (학생 입장)
1. 학교 이름으로 **입장**해요.
2. **스마트 실측** 탭에서 키·몸무게·어깨너비를 넣어요.
3. **맞춤 추천** 탭에서 오늘 계절을 고르고 **[AI 추천 받기]** 를 눌러요.
4. AI가 "○○ 코디처럼 입어 보세요!"와 함께 최대 **3개**를 보여 줘요.
5. 마음에 드는 코디의 **[신청하기]** 를 눌러요.
6. **선생님이 확인**한 뒤 옷을 받아요. → 랭킹에 점수가 쌓여요. (준 사람 +1, 받은 사람 +1)

---

## 2. 추천해도 되는 옷 (옷장 조건)
아래를 **모두** 만족하는 옷만 AI에게 보내요.

| 조건 | 이유 |
|------|------|
| 상태가 **나눔 가능** | 이미 신청됐거나 나눔이 끝난 옷은 빼요 |
| **세탁·검수 완료** (선생님 확인) | 깨끗하고 망가지지 않은 옷만 |
| 옷 상태가 "아주 좋음 / 좋음 / 보통" | "나쁨"은 추천하지 않아요 |
| **내가 준 옷이 아님** | 내가 기부한 옷을 다시 추천하지 않아요 |
| 오늘 계절에 입을 수 있음 | 겨울에 반바지 X |

---

## 3. 사이즈 규칙 (실측 탭과 똑같이)
1. 키 호수: 키를 10 단위로 반올림 (142cm → 140호)
2. 몸무게 호수: ~27kg 130호 · ~33kg 140호 · ~41kg 150호 · ~50kg 160호
3. 둘 중 **더 큰 호수**가 내 사이즈
4. 내 사이즈 **±10호**인 옷만 써요
5. **상의**는 옷 어깨가 내 어깨보다 좁으면 빼요

> 실측 탭과 추천 탭이 **같은 사이즈**를 보여 줘야 아이들이 헷갈리지 않아요.

---

## 4. 잘 입은 코디 예시 모으기
AI가 따라 할 "교과서"예요. 예시가 많을수록 추천이 좋아져요. (= AI가 배우는 방법)

### 모으는 방법
1. 옷 잘 입은 사람을 보고 **상의·하의의 종류와 색만** 적어요. **사진은 저장하지 않아요.** (초상권)
2. 코디 이름, 어울리는 계절, 한 줄 설명을 붙여요.
3. 학생이 **제안** → 선생님이 **승인**하면 예시 목록에 들어가요.
4. 계절마다 예시를 **최소 3개** 모아요.

### 예시 코디
| 이름 | 상의 | 하의 | 계절 |
|------|------|------|------|
| 편안한 체육 코디 🏃 | 맨투맨 · 회색 | 트레이닝바지 · 남색 | 봄, 가을 |
| 꾸안꾸 회색 코디 🩶 | 맨투맨 · 회색 | 트레이닝바지 · 검정 | 가을, 겨울 |
| 청청 코디 👖 | 반팔티 · 하늘색 | 청바지 · 파랑 | 봄, 여름 |
| 산뜻한 여름 코디 🌿 | 반팔티 · 흰색 | 반바지 · 초록 | 여름 |
| 따뜻한 등굣길 코디 🧣 | 후드티 · 베이지 | 면바지 · 갈색 | 가을, 겨울 |
| 봄 소풍 코디 🌸 | 셔츠 · 하늘색 | 면바지 · 베이지 | 봄 |

### 이름 약속 (모두 같은 말로 적어요)
- 상의 종류: `반팔티` `긴팔티` `맨투맨` `후드티` `셔츠`
- 하의 종류: `청바지` `트레이닝바지` `면바지` `반바지` `치마`
- 색 묶음 (같은 묶음 = 비슷한 색)

| 묶음 | 색 |
|------|----|
| 무채색 | 흰색, 회색, 검정 |
| 파랑 | 하늘색, 파랑, 남색 |
| 따뜻한 색 | 빨강, 주황, 노랑, 분홍 |
| 초록 | 초록, 연두 |
| 갈색 | 베이지, 갈색 |

## 5. AI가 따라 하는 기준 ⭐ (핵심 규칙)
AI에게 이 기준을 그대로 알려 줘요. 우리 코드도 똑같이 계산할 수 있어야 해요. (6번)

1. 예시 코디마다 **상의는 상의끼리, 하의는 하의끼리** 내 옷장에서 닮은 옷을 찾는다.
2. 아래 순서대로 찾고, 찾으면 멈춘다.

| 순서 | 찾는 옷 | 닮은 정도 |
|------|---------|-----------|
| 1 | 종류 같음 + 색 같음 | 🟢 똑같아요 |
| 2 | 종류 같음 + 비슷한 색 (같은 묶음) | 🟡 거의 비슷해요 |
| 3 | 종류만 같음 | 🟠 모양이 비슷해요 |
| - | 같은 종류가 없음 | 이 예시는 건너뜀 |

3. 같은 순서의 옷이 여러 벌이면 **상태가 더 좋은 옷**, 그것도 같으면 **먼저 등록된 옷**.
4. 코디 전체 닮은 정도 = 상의·하의 중 **덜 닮은 쪽**
5. 🟢 → 🟡 → 🟠 순서로 **최대 3개**. 같은 내 옷 조합은 한 번만.
6. 코디마다 초등학생이 이해할 수 있는 **한 문장 이유**를 쓴다.
7. **보낸 목록에 없는 옷은 절대 고르지 않는다.**

### AI 답 모양
```json
{ "looks": [
  { "lookId": "L1", "topId": "c6", "bottomId": "c3",
    "match": "똑같아요", "reason": "회색 맨투맨과 남색 바지라서 예시처럼 편하고 깔끔해요" }
] }
```

## 6. AI 답 검사 + AI가 안 될 때
### AI 답 검사 (우리 코드)
- 옷 번호와 예시 번호가 **보낸 목록에 있는지** → 없으면 그 코디만 빼요.
- `topId`는 상의, `bottomId`는 하의인지 → 아니면 빼요.
- 예시와 **종류가 같은지** → 아니면 빼요.
- 3개가 넘으면 앞의 3개만.

### AI가 안 될 때 (대체 추천)
아래 경우에는 **5번 기준을 우리 코드로 직접 계산**해서 보여 줘요.
- 로컬 서버(`python -m http.server`)에서 실행할 때
- 인터넷이 안 될 때, AI가 **20초** 안에 답하지 않을 때
- AI 답을 검사했더니 남은 코디가 없을 때

화면 안내: "AI 대신 규칙으로 찾은 추천이에요 🙂"

- 👍/👎 결과는 모아 두었다가, 👍가 많은 예시를 다음 달에 **먼저** 보여 줘요.

## 8. 신청 규칙 (실제 운영)
| 규칙 | 내용 |
|------|------|
| 신청 한도 | 한 사람당 **일주일에 최대 3벌** |
| 먼저 신청한 사람 우선 | 신청한 옷은 "신청 중"으로 바뀌고 다른 친구 추천에서 빠져요 |
| 받기 | 선생님이 확인하고 전해 줘요. 받으면 "나눔 완료" |
| 기한 | 신청하고 **3일** 안에 안 받으면 다시 "나눔 가능" |
| 취소 | 받기 전에는 취소할 수 있어요 |
| 다시 나눔 금지 | 받은 옷은 다른 친구에게 다시 나눌 수 없어요 (랭킹 규칙과 같음) |
| 점수 | 나눔이 끝나면 랭킹에 기록돼요 (준 사람 +1, 받은 사람 +1, 하루 최대 3점) |

## 11. 계산 예시 (대체 추천으로 계산, AI도 같은 답이어야 해요)
조건: 키 142cm · 몸무게 36kg · 어깨 31cm → **150호** (140~160호 사용), **가을**

- 쓸 수 있는 상의: 회색 맨투맨(140, 어깨 34)
- 쓸 수 있는 하의: 남색 트레이닝바지(140) — 초록 반바지는 여름옷이라 빠짐

| 예시 | 상의 | 하의 | 결과 |
|------|------|------|------|
| 편안한 체육 코디 | 회색 맨투맨 🟢 | 남색 트레이닝바지 🟢 | 🟢 **추천** |
| 꾸안꾸 회색 코디 | 회색 맨투맨 🟢 | 남색 트레이닝바지 🟠 | 위와 같은 조합이라 빠짐 |
| 따뜻한 등굣길 코디 | 후드티 없음 | - | 건너뜀 |

→ **편안한 체육 코디 1개**

## 13. AI 연결과 안전 약속
- **API 키는 브라우저 코드에 넣지 않아요.** Vercel 서버 함수 `api/recommend.js`가 대신 물어봐요. 키는 선생님이 Vercel 설정에만 넣어요.
- npm 없이 `fetch`로 Claude API를 불러요. 모델: `claude-opus-5-5` (더 저렴한 모델은 선생님이 정해요)
- **[AI 추천 받기] 를 눌렀을 때만** AI를 불러요. 같은 조건이면 다시 부르지 않고 저장해 둔 답을 써요. (비용 절약)
- AI에게는 **이름을 보내지 않아요.** 사이즈가 맞는 옷 정보와 예시 코디만 보내요.
- 진짜 AI 테스트는 PR을 올리면 생기는 **Vercel 미리보기 주소**에서 해요.

## 16. 다른 모듈과의 약속
- 몸 정보(`state.student`)는 **읽기만** 해요. 바꾸는 건 실측 모듈이에요.
- 사이즈 계산은 **실측 탭과 같은 규칙**을 써요. 규칙이 바뀌면 실측 담당과 같이 바꿔요.
- 나눔이 끝난 기록은 랭킹 모듈이 점수를 계산해요. (`giver`, `receiver`, 옷 번호, 날짜)
- 다른 학생의 파일(`measurement.js`, `ranking.js`)은 고치지 않아요.
- `mockData.js`에 정보를 더하거나 `api/` 폴더를 만들 때는 팀에게 먼저 말해요.
