 FitShare 추천 규칙

## 목표

학생에게 잘 맞고 학교에서 편하게 입을 수 있는 옷과 코디를 추천한다.

## 추천 기준

추천 순서는 다음 기준을 사용한다.

1. 내 사이즈와 맞는가
2. 계절과 날씨에 맞는가
3. 옷 종류가 필요한 것과 맞는가
4. 내가 고른 색상과 스타일에 가까운가
5. 옷 상태가 좋은가

## 학생이 고르는 조건

- 상의·하의·외투
- 따뜻한 옷·시원한 옷
- 편한 스타일·활동적인 스타일
- 밝은 색·어두운 색
- 남자 옷 / 여자 옷

## 추천 점수

| 조건 | 점수 |
| --- | ---: |
| 사이즈 일치 | 4점 (명시적 인접 허용은 3점) |
| 계절 일치 | 2점 |
| 옷 종류 일치 | 2점 |
| 스타일 일치 | 1점 |
| 상태 좋음 | 1점 |

기본점수에 명시적으로 선택한 스타일·색상 선호 일치 보너스(각 2점)와 기준 옷 치수의 근접도(0~4점)를 반영해 정렬한다. 화면 점수는 1~10으로 제한하지만 실제 순서는 소수 근접도까지 사용한다. 기준 치수의 목표와 평균 차이를 d cm라 할 때 근접도는 `4 / (1 + d/3)`이다. 치수를 입력하지 않으면 근접도를 가산하지 않는다.

## 결과 표시

- 한 번에 추천 코디 3개를 보여 준다.
- 추천 이유를 쉬운 말로 함께 보여 준다.
- 예: `내 사이즈와 잘 맞아요`, `봄에 입기 좋아요`.
- 먼저 필수 조건을 모두 만족하는 옷만 남긴 뒤 점수로 정렬한다. 스타일·색상도 기본값은 필수이며 사용자가 선호로 바꾼 경우에만 다른 값을 후보에 포함한다. 최대 3벌이며 부족한 수를 불일치 옷으로 채우지 않는다.
- 공용은 남학생·여학생 모두 포함한다. male/female 등록값을 선택값과 정규화하며 미등록 정보는 선택 조건에 일치로 간주하지 않는다.
- 추천할 옷이 없으면 0벌임을 안내한다. 사용자가 조건을 변경하거나 전체를 선택하면 검색 범위를 넓힌다. 자동으로 조건을 완화하지 않는다.

## 세부 조건과 상·하의 세트 매칭

- 기본 조건은 모두 만족해야 한다. 사이즈 허용 범위는 기본 0이며 사용자가 ±10을 선택한 경우에만 인접 사이즈를 포함한다. 정확한 사이즈는 기존 4점, 허용 범위 안의 인접 사이즈는 3점으로 정렬한다.
- 세부 색상·옷 상태와 길이·너비(cm)의 최소·최대값을 추가 조건으로 사용할 수 있다. 치수는 몸 치수가 아니라 옷 치수이며 상의 너비는 가슴 단면, 하의 너비는 허리 단면이다. 잘못된 수치·범위는 안내하고 결과를 표시하지 않는다.
- TOP 3의 `이 옷으로 세트 찾기`로 상의 또는 하의를 선택한다. 상의를 고르면 하의, 하의를 고르면 상의를 찾고 항상 상의·하의 두 사진을 함께 표시한다. 세트는 최대 3개다.
- 반대 옷의 사이즈는 기본적으로 선택 옷과 같지만 사용자가 별도로 선택할 수 있다. 계절 교집합, 허용 사이즈, 선택한 성별(공용 포함)·필수 스타일·옷 상태·두께·신축성을 만족해야 한다. 첫 옷의 종류·색상·길이·너비·기준 치수는 반대 옷에 복사하지 않는다.
- 세트 원점수는 사이즈 4점(허용 인접 3점), 공통 계절 2점, 같은 스타일 1점, 색상 조화 2점, 두께 호환 2점, 무지와 무늬 조합 1점이다. 12점 원점수로 정렬하고 화면은 10점 기준으로 표시한다. 색상은 기본색·명도 대비 또는 비슷한 계열 중 사용자가 우선순위를 선택한다. 조합 규칙은 편집 기준이며 실제 착용 적합성을 보증하는 수치가 아니다.
- 조건을 바꾸면 기존 선택과 세트를 초기화한다. 세트 선택 시 서버 목록을 다시 읽어 삭제·수정된 옷을 확인하며 늦게 도착한 이전 요청으로 새 조건을 덮어쓰지 않는다. 일치하는 짝이 없으면 없다고 안내하고 조건을 자동 완화하지 않는다.

## 정보 등록과 착용감 비교

- 등록·정보 수정에 단일 호칭 사이즈, 여러 계절, 스타일·상태, 세부 종류, 소매·바지 길이, 두께·신축성·무늬를 저장한다. 상태·두께·신축성은 사진이나 치수로 자동 확정하지 않는다.
- 로그인 등록자, 사진 분석 성공 시의 색상·실측을 자동 입력한다. 명시된 이름·선택한 종류로 확인 가능한 항목만 제안하고 근거를 표시한다. 직접 고친 값은 이후 자동 제안으로 덮어쓰지 않는다. 알 수 없으면 미등록으로 두고 본인이나 선생님이 정보 수정에서 보완할 수 있다.
- 자동 분석이 어려우면 사진과 종류를 선택하고 직접 입력 경로를 이용한다. 자로 잰 길이·너비와 색상을 입력해야 저장되며 입력 방식을 manual로 기록한다. 사진 실측은 photo-analysis로 구분한다. 세그멘테이션 방식은 바꾸지 않는다.
- 기준 옷은 현재 잘 맞는 같은 종류의 옷이다. 상의 가슴 단면과 하의 허리 단면을 섞지 않도록 비교 시 종류 선택이 필요하다. 비슷하게/조금 여유/여유는 목표 단면 너비에 0/2/4cm를 더하는 명시적 정렬 기준이며, 호칭 ±10을 길이 10cm로 해석하지 않는다.
- 체험 데이터의 스타일·상태·두께·신축성·치수는 가상 예시이며 metadataSources의 demo로 구분한다. 실제 등록의 알 수 없는 값을 체험 값으로 채우지 않는다.

## 개인정보와 공정성

- 키와 몸무게는 추천에만 사용하고 다른 학생에게 공개하지 않는다.
- 성별이나 외모로 옷을 제한하지 않는다.
- 같은 옷만 반복 추천하지 않는다.

## 랭킹 연결

- 추천 코디 확인: +2점
- 추천 옷 저장: +3점
- 추천받은 옷 나눔 완료: +20점

실제 나눔 활동에 가장 높은 점수를 준다.
# 원하는 옷 기부 알림

- 기본 추천 조건(입을 사람·사이즈·계절·종류·스타일·색상)을 그대로 저장한다. 조건 하나 이상을 선택해야 하며 계정당 최대 20개, 같은 조건 중복 등록은 불가하다.
- 저장 이후 새로 등록된 실제 기부 옷에만 적용한다. 저장 시 이미 등록되어 있던 옷과 체험 데이터는 알리지 않는다. 모든 지정 조건이 맞아야 하며 공용 옷은 남학생/여학생 모두, 복수 계절 옷은 해당 계절에 일치한다. 지정 정보 미등록은 일치로 추정하지 않는다.
- 추천 탭에서 30초마다 새 알림을 확인하고 수동 갱신도 제공한다. 탭 재방문 시에도 저장 이후 들어온 옷을 확인한다. 알림에서 옷 상세를 열고 읽음 처리하거나 해당 조건의 알림을 해제할 수 있다. 삭제된 옷은 표시하지 않는다.
- 로그인한 본인 계정만 저장 조건과 알림에 접근한다. 알림은 앱 내부에 표시하며 외부 메시지나 브라우저 푸시를 발송하지 않는다.
