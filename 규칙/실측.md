담당 파일: `modules/measurement.js`

## 처음 정한 규칙
```
격자를 1cm로 재서 옷의 크기 측정
```

## 지금 만든 것: 내 몸에 맞는 옷 찾기
키·몸무게·어깨너비를 넣으면 맞는 옷을 찾아 줘요.

1. **키 호수**: 키를 10 단위로 반올림 (142cm → 140호)
2. **몸무게 호수**: 아래 표로 정해요

   | ~27kg | ~33kg | ~41kg | ~50kg |
   |-------|-------|-------|-------|
   | 130호 | 140호 | 150호 | 160호 |

3. 둘 중 **더 큰 호수**가 내 사이즈
4. 내 사이즈 ±10호인 옷만 보여 줘요 → 딱 맞아요 / 조금 커요 / 조금 작아요
5. **상의**는 어깨도 비교해요
   - 옷 어깨가 내 어깨보다 좁으면 빼요
   - 0~4cm 넓으면 "어깨 딱 맞아요", 그보다 넓으면 "어깨가 넉넉해요"

입력 범위: 키 80~200cm · 몸무게 10~120kg · 어깨 20~60cm (벗어나면 안내 문구)

## 예시
키 142cm, 몸무게 36kg → 키 140호, 몸무게 150호 → **150호**

## 테스트
| 종류 | 입력 (키/몸무게/어깨) | 결과 |
|------|----------------------|------|
| 정상 | 142 / 33 / 31 | 140호, 5벌 (어깨가 좁은 반팔 티는 빠짐) |
| 경계 | 몸무게 33 → 33.1 | 140호 → 150호 |
| 오류 | 몸무게 빈칸 | "몸무게를 입력해 주세요." |
